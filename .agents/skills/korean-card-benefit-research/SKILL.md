# 국내 카드 혜택 검색

## 검색과 출처 확인

1. 기업·판매처, 카드사·상품명, 구매일, 결제 채널을 검색 입력으로 사용한다. 판매처 한정 행사, 법인·사업자 카드, 특정 조직의 임직원 전용을 각각 확인한다. 여러 조건이 겹치면 모두 기록한다.
2. 카드사 상품 상세에서 `상품설명서`, `상품안내장`, `주요거래조건` PDF를 연다. 같은 카드의 `부가서비스 변경` 공지와 판매처 공식 `카드 할인`, `청구할인`, `행사 유의사항`을 검색한다. 직접 PDF 링크가 필요한 경우 `site:<카드사 공식 도메인> filetype:pdf "<카드 상품명>"`을 사용한다. 카드사 공식 상세에서 연결한 CDN PDF도 출처로 인정한다.
3. 카드 상품명·발급 대상·버전을 확인하고 주문일에 적용되는 변경 공지가 있는지 대조한다. 공지일, 시행일, 행사 기간을 각각 기록한다. 검색 미리보기는 문서 발견에 사용하고, 원문에서 확인된 조건만 근거에 넣는다. 원문이 없거나 출처끼리 충돌하면 확인 필요 상태와 이유를 남긴다.
4. PDF에서 본문, 한도 표, 각주, 제외 조건을 함께 읽는다. 표의 열 순서가 깨지거나 스캔본이면 해당 쪽을 렌더링해 눈으로 확인하고 필요하면 OCR을 보조로 쓴다. 원문의 PDF 페이지 번호 또는 웹 섹션을 각 규칙에 연결한다. 로그인 전용 공지는 사용자에게 공유 권한이 있는 문서나 필요한 조건만 제공받는다.

## 결과 필드

| 필드 | 남길 값 |
| --- | --- |
| 상품과 자격 | 카드사, 상품명·식별자, 카드 유형, 대상 기업·회원, 발급 조건 |
| 사용 조건 | 판매처·업종, 온라인·오프라인, 직접 카드 결제·간편결제·PG, 행사 신청 여부, 최소 결제액과 전월 실적, 제외 거래 |
| 할인과 한도 | 즉시할인·청구할인·적립, 정액 또는 비율, 금액·포인트·마일리지 단위, 건별·월별 한도, 카드·회원·법인 중 한도가 적용되는 범위, 중복 가능 여부 |
| 기간과 출처 | 행사 시작·종료 및 규칙 시행일, 공식 안내 URL, PDF URL과 쪽수 또는 웹 섹션, 문서 버전, 확인일, 충돌·미확인 조건 |

금액은 원 단위 정수로 기록한다. 전월 실적, 응모 상태, 남은 한도, 실제 승인 가맹점 분류는 해당 주문을 확인해야 하는 값으로 둔다. 카드번호·로그인 정보는 수집 대상에서 제외한다. 사용자에게는 요약 조건과 근거 링크를 제공하며 원본 PDF는 각 출처의 공개 링크를 참조한다.

FCC는 확인된 즉시할인, 조건부 청구할인, 추후 적립을 따로 표시한다. 장바구니에 포함된 할인은 한 번만 반영한다. 혜택가 산정 방식은 [DATA_SOURCES.md](../../../DATA_SOURCES.md#국내-기업-한정-카드-혜택가)를 참고한다.
