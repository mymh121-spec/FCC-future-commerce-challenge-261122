# 고객 기기에 둘 파일

고객이 기본 배송지 저장을 선택하면 고객 기기의 앱 전용 데이터 디렉터리에 계정별 암호화 파일 `buyer_profile.enc`를 저장한다. 파일에는 수령인 이름, 연락처와 배송지를 담는다. 저장을 선택하지 않은 고객은 판매처 결제창에 직접 입력한다.

- 파일은 인증 암호화하고 계정별 암호화 키는 해당 기기의 OS 키링에 둔다. 공용 기기에서 계정을 전환하면 이전 프로필을 닫고 해당 계정의 파일과 키만 연다. 고객이 프로필 삭제를 선택하면 파일과 해당 키를 함께 지운다.
- Streamlit의 Python 프로세스가 쓰는 파일은 그 프로세스가 실행되는 기기에 생긴다. 서버에 배포할 때 고객의 로컬 파일 기능은 브라우저나 설치형 클라이언트가 담당해야 한다. 현재 MVP는 고객 기기에서 아래 CLI로 읽고 쓴다. 로컬 프로필 이름은 같은 OS 사용자 안에서 파일을 구분하는 용도다. 기기를 다른 사람과 공유할 때는 각자의 OS 사용자 계정을 사용한다.
- 음성 입력과 이번 검색어는 현재 검색 세션에서 처리한다. 해외 검색에서 번역이 필요하면 검색어가 외부 번역 서비스로 전달된다. 음성 원본과 전체 검색 이력을 프로필에 추가하지 않는다.
- 카드번호와 보안코드는 결제사 입력창에서, 개인키와 복구 문구는 고객 지갑에서 관리한다. FCC 프로필의 필드는 배송에 필요한 값으로 한정한다.


## 실행

Ubuntu 데스크톱의 시스템 Python과 잠금 해제된 Secret Service 키링을 사용한다. 필요한 시스템 패키지는 `python3-cryptography`, `python3-gi`, `gir1.2-secret-1`이다. 프로젝트 루트에서 실행한다.

```sh
python3 api_data/buyer_local.py save
python3 api_data/buyer_local.py read --field address
python3 api_data/buyer_local.py delete
```

`save`는 수령인, 연락처, 주소를 화면에 표시하지 않고 입력받아 전체 프로필을 교체한다. `read`는 지정한 필드 하나를 현재 터미널에 표시한다. 기본 경로는 `~/.local/share/fcc-buyer/` 아래이고 `XDG_DATA_HOME` 설정을 따른다. 프로필을 여러 개 쓸 때만 각 명령에 `--account 이름`을 붙인다. 키링 키를 잃으면 해당 파일은 복구할 수 없다.
